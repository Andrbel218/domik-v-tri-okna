## Как проверялось

1. Все HEIC декодированы в JPEG-прокси (длинная сторона 2000 px) через `sips`.
2. Каждая пара «нарезка × фото» проверена SIFT-сопоставлением с RANSAC-гомографией (OpenCV SIFT, Lowe ratio 0.75–0.88, порог 5 инлайеров).
3. Кандидаты с наибольшим числом инлайеров просмотрены глазами; ложные совпадения по одинаковому орнаменту отброшены.
4. Дубли среди файлов заказчика найдены по MD5.
