# Домик в три оконца

Одностраничный сайт-визитка мастера Андрея Беляева: деревянные домики, магниты,
конфеты-самоцветы и новогодний декор ручной работы.

Сайт собран из материалов презентации заказчика. Порядок блоков соответствует
порядку загрузки слайдов.

## Структура

- `index.html` — разметка страницы
- `styles.css` — стили
- `script.js` — меню, лайтбокс, анимации появления
- `assets/img/slides/` — исходные слайды презентации
- `assets/img/gallery/` — фотографии, вырезанные из слайдов
- `assets/img/hero-main.jpg` — фото для первого экрана
- `assets/img/quote-bg.jpg` — фон блока с цитатой
- `assets/img/logo-correct.png` — полный логотип для подвала
- `assets/img/logo-mark.jpg` — знак дома для шапки
- `assets/favicon.svg` — иконка сайта

## Локальный просмотр

```bash
python3 -m http.server 8000
```

Открыть http://localhost:8000

## Публикация

GitHub Pages, ветка `main`, папка `/ (root)`.

Адрес: https://andrbel218.github.io/domik-v-tri-okna/

После правок в CSS или JS увеличивайте номер версии в `index.html`
(`styles.css?v=15`, `script.js?v=15`) — иначе браузеры могут показывать
старую версию из кеша.

## Что заменить после получения материалов

1. **Текст об идее** — вставлен в блок «Маленькие дома и вещи с историей»
   (про реставрацию дома в Старой Купавне). Первый экран остаётся вводным.
2. **Цены** — в презентации суммы не указаны, поэтому везде «по запросу».
   После получения цен добавить их в блок `#ceny` (`.price-row`).
3. **Подпись на слайде с магнитами** — «Следеной / И просто так» прочитана
   неоднозначно, на сайте оставлено «И просто так». Уточнить у заказчика.
4. **Контакты** — сейчас только телефон. Добавить мессенджеры/соцсети, если нужны.
5. Цитата на первом экране оставлена как в презентации, с многоточием.
